# Сайт памяти Ревомира Баяровича Гармаева

Статический сайт на [Astro](https://astro.build). Домен — гармаев.рф
(`xn--80aagbm4b1a.xn--p1ai`). Домен, DNS и хостинг — у Reg.ru, тариф Host-A.
Как выложить в прод — в [DEPLOY.md](DEPLOY.md).
Превью: https://zmovikvadim.github.io/garmaev/

Ревомир Баярович Гармаев (2 февраля 1938 — 12 сентября 2019) — журналист и редактор,
пятнадцать лет главный редактор газеты «Буряад үнэн», заместитель председателя
Верховного Совета и правительства Бурятии, руководитель администрации первого
президента республики, председатель республиканского совета ветеранов. Почётный
гражданин Республики Бурятия.

## Что где лежит

```
Photos/                     оригиналы сканов, разложенные по альбомам (не трогаются сборкой)
draft/
  biography.md              исходный текст биографии
  materials.md              подборка публикаций о нём в сети + что ещё стоит найти
site/
  scripts/prepare-photos.mjs   готовит галерею из ../Photos
  src/
    data/site.json          имя, даты, контакт, меню
    data/quotes.json        цитаты
    data/publications.json  внешние публикации для раздела «Статьи»
    data/gallery.json       манифест галереи — генерируется скриптом, вручную не править
    content/articles/*.md   статьи с полным текстом
    pages/                  страницы
    pages/_book.astro       страница книги — скрыта, из сборки исключена
    styles/global.css       вся вёрстка
  public/gallery/           готовые снимки — генерируются скриптом
```

## Работа с проектом

```bash
cd site
npm install
npm run photos   # пересобрать галерею из ../Photos (нужно после правки альбомов)
npm run dev      # http://localhost:4321
npm run build    # результат в site/dist — это и заливается на хостинг
npm run deploy   # собрать и залить на прод по FTP (нужен .env.deploy, см. DEPLOY.md)
```

Обычно заливать вручную не нужно: push в `main` собирает сайт и публикует его на
гармаев.рф через GitHub Actions.

`npm run photos` очищает `public/gallery` и собирает её заново: делает три размера
каждого снимка — 1800px для полного просмотра, 700px для ленты и 200px квадратом
для ряда пиктограмм, — конвертирует `.tif`, поворачивает по EXIF. Порядок
альбомов, их названия и периоды заданы в массиве `ALBUMS` в начале
[scripts/prepare-photos.mjs](site/scripts/prepare-photos.mjs).

## Как дополнять

**Новая статья.** Положите `.md` файл в `site/src/content/articles/`. Обязательные
поля во фронтматтере — `title` и `dek`; остальные (`author`, `publication`,
`dateNote`, `sourceUrl`, `order`) по желанию. Имя файла становится адресом страницы.

**Новая цитата.** Добавьте объект в `site/src/data/quotes.json`. Поле
`"featured": true` выносит цитату на плашку главной страницы — оно должно быть
только у одной.

**Новые фотографии.** Положите в нужную папку внутри `Photos/` и запустите
`npm run photos`. Чтобы под снимком появилась подпись, назовите файл осмысленно —
имя файла становится подписью. Служебные имена вида `DSCN0561.JPG` или
`Изображение 004.jpg` подписью не считаются и отбрасываются.

**Новый альбом.** Создайте папку в `Photos/`, добавьте запись в `ALBUMS` в
`prepare-photos.mjs` — позиция в массиве задаёт порядок на сайте.

**Убрать снимок с сайта.** Добавьте `«папка/имя файла»` в набор `EXCLUDE` в
`prepare-photos.mjs` и запустите `npm run photos`. Оригинал остаётся в `Photos/`,
со страниц снимок исчезает — решение обратимо. Сейчас исключён один файл:
`Работа/Изображение 006.jpg`.

**Форма обратной связи.** Страница `/contact` отправляет заявки через Web3Forms на
почту аккаунта `zmovik@gmail.com`. Публичный ключ формы лежит в
`site/src/data/site.json` в поле `formAccessKey` — он предназначен для клиентского
кода, поэтому открыто в репозитории ему быть нормально. Адрес почты в разметку не
попадает. Если ключ очистить, вместо формы на странице появится пояснение.

Важно: бесплатный план Web3Forms принимает отправку только из браузера — POST с
сервера возвращает 403. На статическом сайте это и происходит, так что ограничение
ни на что не влияет. Лимит — 250 писем в месяц; вложения и несколько получателей
доступны только на платном плане, поэтому форма просит описать материалы словами.

**Скан книги.** Страница книги сейчас скрыта: файл называется `_book.astro`, и
Astro такие файлы не собирает, поэтому адреса `/book` на сайте нет. Чтобы вернуть —
переименуйте его в `book.astro`, добавьте пункт `{ "href": "/book", "label": "Книга" }`
в `nav` в `site.json` и верните ссылки на неё в `index.astro` и `biography.astro`.
Сами файлы скана положите в `site/public/book/` и заполните массив `downloads`
внутри страницы — кнопки скачивания появятся вместо заглушки.
