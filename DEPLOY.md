# Выкладывание сайта на гармаев.рф

Домен, DNS и хостинг — всё у Reg.ru. Сайт статический: на сервере не нужны ни PHP, ни
база данных, только отдача файлов.

Кириллический домен везде может отображаться в punycode — это одно и то же:

```
гармаев.рф  =  xn--80aagbm4b1a.xn--p1ai
```

Состояние на 19 августа 2026 года, проверено по реестру и DNS:

| Что | Значение |
|-----|----------|
| Регистратор | Reg.ru (`REGRU-RF`), домен с 9 октября 2020, оплачен до 9 октября 2027 |
| NS-серверы | `ns1.reg.ru`, `ns2.reg.ru` — зоной управляет Reg.ru |
| A-запись `@` и `www` | `92.255.111.71` — общий адрес Craftum |
| Где сейчас сайт | Craftum (конструктор на инфраструктуре Timeweb) |
| MX-записи | отсутствуют, почта на домене не настроена |

Поскольку DNS уже у Reg.ru, при заказе там же хостинга записи домена настраиваются
из той же панели — отдельно править зону, скорее всего, не придётся.

## Шаг 1. Собрать сайт

```bash
cd site && npm run build
```

Готовый сайт — в `site/dist`. **Заливать нужно содержимое `dist`, а не саму папку**:
`index.html` должен оказаться в корне сайта, а не в `dist/index.html`.

Сборка по умолчанию рассчитана на корень домена — именно то, что нужно. Переменные
`SITE_BASE`/`SITE_URL` задавать не надо, они нужны только для превью на GitHub Pages.

Проверьте, что в `dist` попали:

- `index.html`, папки `biography`, `gallery`, `quotes`, `articles`, `contact`
- `404.html` — страница «такой страницы нет»
- `robots.txt`, `sitemap-index.xml`, `sitemap-0.xml`
- `.htaccess` — правила Apache: https, без www, кэширование, обработка 404
- `_astro` — стили и скрипты
- `gallery` — 60 снимков в трёх размерах, около 11 МБ

## Шаг 2. Заказать хостинг

Берите **Host-A** — по сравнению тарифов это минимальный, на котором есть всё нужное.

| | Host-Lite (130 ₽) | **Host-A (214 ₽)** | Host-B (323 ₽) |
|---|---|---|---|
| Место под файлы | 7 ГБ | 7 ГБ | 25 ГБ |
| Бесплатный SSL | **нет** | да | да |
| `.htaccess` и редиректы | **нет** | да | да |
| FTP | да | да | да |
| Автоматический бэкап | да | да | да |
| Сайтов на тарифе | 15 | 1 | 1 |

**Host-Lite не подходит**, хотя и дешевле: на нём нет бесплатного SSL, то есть сайт
открывался бы только по http и браузеры показывали бы «Не защищено» — для сайта памяти
с формой обратной связи это неприемлемо. Там же нет `.htaccess`, а с ним пропадают
страница 404, редирект с www и кэширование.

Host-A с запасом: сайт весит около 15 МБ при 7 ГБ места, и одного сайта на тарифе нам
достаточно. Цена «от 214 ₽/мес» — это при оплате сразу за 36 месяцев; при оплате
месяцем выйдет дороже, точную сумму покажет корзина.

## Шаг 3. Привязать домен к хостингу

В панели хостинга добавьте сайт для домена `гармаев.рф`. Если поле не принимает
кириллицу, введите `xn--80aagbm4b1a.xn--p1ai`.

Так как DNS домена обслуживает Reg.ru, панель сама поставит нужную A-запись вместо
текущей `92.255.111.71`. **Проверьте это** — в управлении DNS-зоной домена записи `@` и
`www` должны указывать на адрес вашего хостинга. Если панель их не изменила, поправьте
руками; новый адрес показан в разделе хостинга.

Панель создаст на сервере каталог сайта — обычно вида `/www/гармаев.рф`. **Точный путь
посмотрите в панели**, он и есть корень сайта.

Как только A-запись сменится, посетители пойдут на новый хостинг, где файлов ещё нет, и
несколько минут будут видеть заглушку. Поэтому делайте шаги 3 и 4 подряд, не откладывая
заливку. Если хотите обойтись совсем без заглушки — создайте сайт в панели, залейте
файлы и только потом смените A-запись домена на адрес хостинга.

## Шаг 4. Залить файлы

Вариант через файловый менеджер панели: откройте каталог сайта, удалите то, что
хостинг положил туда сам (обычно `index.html` с заглушкой), загрузите содержимое
`dist`.

Вариант из терминала — удобнее при обновлениях. Понадобится `lftp`
(`brew install lftp`):

```bash
lftp -u ВАШ_ЛОГИН,ВАШ_ПАРОЛЬ ftp.гармаев.рф -e "mirror -R --delete --verbose --parallel=4 site/dist /www/гармаев.рф; bye"
```

Адрес FTP-сервера, логин, пароль и точный путь возьмите в панели Reg.ru — они выдаются
при создании хостинга и могут отличаться от примера.

Флаг `--delete` убирает на сервере то, чего больше нет в сборке, — иначе со временем
накопятся файлы удалённых снимков.

> **Внимание на `.htaccess`.** Файл начинается с точки, и FTP-клиенты часто скрывают
> такие файлы, а файловые менеджеры не показывают их по умолчанию. Если он не
> зальётся, сайт будет работать, но без принудительного https, без редиректа с www и
> без нормальной страницы 404. После заливки проверьте, что он на месте.

## Шаг 5. Дождаться DNS и выпустить сертификат

Изменения расходятся обычно за 15–30 минут, изредка дольше. Проверить, куда уже
смотрит домен:

```bash
dig +short xn--80aagbm4b1a.xn--p1ai
```

Когда в ответе появится адрес вашего хостинга, в панели Reg.ru выпустите бесплатный
сертификат Let's Encrypt для домена — **раньше он не выпустится**, проверка идёт через
тот самый домен. После выпуска включите в панели перенаправление на https.

Правило принудительного https есть и в `.htaccess`, но включать его до выпуска
сертификата нельзя: получите бесконечный редирект на адрес, который ещё не работает.
Если сертификата пока нет, а сайт уже нужен — закомментируйте в `.htaccess` четыре
строки блока «Только https», залейте, и раскомментируйте после выпуска.

## Шаг 6. Проверить

```bash
# отдаёт ли сайт страницы (ожидаем 200)
for p in "" biography gallery gallery/komsomol quotes articles contact; do
  printf "%s /%s\n" "$(curl -sL -o /dev/null -w '%{http_code}' https://гармаев.рф/$p)" "$p"
done

# редиректы: http и www должны уводить на https без www (ожидаем 301)
curl -sI http://гармаев.рф/ | head -1
curl -sI https://www.гармаев.рф/ | head -1

# страница 404 (ожидаем 404, а не 200 и не страницу хостинга)
curl -s -o /dev/null -w "%{http_code}\n" https://гармаев.рф/такой-страницы-нет

# сертификат
curl -sI https://гармаев.рф/ | head -1
```

Глазами проверьте главное:

- на главной виден портрет, на страницах альбомов листается лента и работает ряд
  пиктограмм
- клик по снимку открывает полноэкранный просмотр со стрелками
- форма на `/contact` отправляется и письмо доходит

Форма обратной связи заработает сразу: ограничение по домену на бесплатном плане
Web3Forms не действует, ключ привязан к аккаунту, а не к адресу сайта.

## Дальнейшие обновления

```bash
cd site
npm run photos   # только если менялись фотографии в Photos/
npm run build
# затем команда lftp из шага 4
```

Полезно после каждой заливки открыть сайт с телефона: страницы кэшируются на
10 минут, так что старая версия может подержаться несколько минут.

## Что стоит сделать после запуска

- Добавить сайт в Яндекс.Вебмастер и Google Search Console, отдать им
  `https://гармаев.рф/sitemap-index.xml`. Для сайта памяти это важнее обычного: люди
  будут искать его по имени.
- Отвязать домен от Craftum и отменить там подписку — старый сайт стоит именно на
  Craftum (проверено по обратной зоне адреса `92.255.111.71`:
  `782969-craftumst.tmweb.ru`). Пока подписка активна, вы платите за конструктор,
  который уже ничего не отдаёт.
- Проверить, что в панели Reg.ru включено автоматическое резервное копирование, — на
  Host-A оно есть. Отдельная копия уже лежит в репозитории на GitHub, включая оригиналы
  сканов.

## Перенос домена к другому регистратору

Не нужен. Домен, DNS и хостинг находятся у Reg.ru — переносить регистратора незачем.
Если когда-нибудь понадобится, порядок для зон `.ru` и `.рф` такой: у текущего
регистратора запрашивается AuthInfo-код (действует 20 календарных дней), затем он
вводится у принимающего. Перенос бесплатный, срок регистрации не продлевает и занимает
около пяти дней. Главное при этом — не забыть перевести домен на NS-серверы нового
регистратора: старый может со временем перестать обслуживать зону, и домен просто
перестанет открываться.

## Если что-то не так

**Открывается заглушка хостинга.** Файлы легли не в корень: проверьте, что
`index.html` лежит прямо в каталоге сайта, а не в его подпапке `dist`.

**Внутренние страницы дают 404, главная работает.** Не залились папки
`biography`, `gallery` и остальные, либо заливка шла без вложенных каталогов.

**Бесконечный редирект.** Принудительный https включён и в `.htaccess`, и в панели
Reg.ru одновременно, либо сертификат ещё не выпущен. Оставьте что-то одно.

**Кириллица в адресе ломается в консоли.** Используйте punycode:
`xn--80aagbm4b1a.xn--p1ai`.

**Картинки не открываются, страницы работают.** Скорее всего не залилась папка
`gallery` целиком — она самая тяжёлая, заливка могла оборваться. Повторите `mirror`,
он догрузит недостающее.
